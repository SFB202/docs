## 1) 인증 / 로그인

### 목적

- 사용자는 **GitHub 계정 연동(OAuth)** 으로 로그인한다.
    

### 기능 요구사항

|기능|상세|
|---|---|
|로그인|GitHub OAuth 연동 로그인|
|세션 유지|로그인 상태 유지(토큰/세션 기반)|
|로그아웃|세션 종료 및 클라이언트 상태 초기화|

---

## 2) 유저 관리

### 목적

- 로그인한 유저의 기본 정보와 방/회의/이슈 등 서비스 내 활동을 식별한다.
    

### 기능 요구사항(초안)

|기능|상세|
|---|---|
|유저 프로필 조회|GitHub 프로필(이름/아이디/아바타 등) 기반|
|권한/역할|방 단위로 역할(관리자/멤버 등) 구분|
|활동 기록|최근 참여 회의/생성 이슈 등 연동 가능한 범위로 기록|

> 현재 “유저 관리” 섹션이 비어있어서, 위처럼 **최소 필요 기능** 기준으로 채워둠.

---

## 3) 마이페이지 (로그인 직후 기본 화면)

### 목적

- 사용자의 최근 활동(회의)을 빠르게 확인한다.
    

### 기능 요구사항

- 최근 참여한 회의 **5~10개** 노출
    
- 회의 리스트 아이템에 아래 정보 표시:
    
    - 회의 제목
        
    - 참가자(요약 형태 가능: “3명”, “A,B 외 2명”)
        
    - 날짜(및 시간)
        

### 데이터 표시 항목

|항목|설명|
|---|---|
|제목|회의 이름|
|참가자|참여자 리스트/요약|
|날짜|회의 진행 일시|

---

## 4) 방 리스트 (사이드바)

### 목적

- 사용자가 참여 중인 방을 빠르게 이동/확인한다.
    

### 기능 요구사항

- 로그인 성공 시, **내가 참가한 방 목록** 표시
    
- 방 리스트 아이템 표시:
    
    - 방 대표 이미지(썸네일)
        
    - 방 이름
        
    - 알림 표시(새 이벤트/미확인 메시지/새 회의록/새 이슈 등)
        

### UI 요구사항(핵심)

|기능|상세|
|---|---|
|방 목록|내가 속한 방 리스트|
|알림 배지|알림 존재 시 아이콘/뱃지 표시|

---

## 5) 방 (Room)

### 목적

- 협업 단위 공간. 레포지토리/회의/이슈/회의록이 방 단위로 묶인다.
    

### 기능 요구사항

- **관리자**는 방 생성 가능(방 이름 입력)
    
- 로그인 후 사용자는 **방 목록 확인**
    
- 사용자는 새 방 생성 가능(권한 정책에 따라 “관리자만”으로 제한 가능)
    
- 방 입장 시:
    
    - 프로젝트(레포지토리)를 **생성하거나 불러오기** 가능
        
- 라운지(방의 메인)에서:
    
    - GitHub ID 검색으로 친구 추가
        
    - 친구 추가 시 **GitHub Collaborator 자동 초대** 연동
        
- 방 내부 사이드바에:
    
    - “진행 중 회의 / 완료된 회의” 리스트 표시
        

### 세부 요구사항

|기능|상세|
|---|---|
|레포지토리 연동|프로젝트 이름 기반으로 새 GitHub 레포 생성 또는 기존 레포 불러오기|
|멤버 초대 연동|GitHub ID 검색 → Collaborator 초대 자동화|
|회의 목록 표시|방 단위로 진행/완료 회의 구분 표시|

---

## 6) 라운지 (Room Dashboard)

### 목적

- 방 단위 활동 요약 + 최근 회의 + 진행 중 이슈를 한 화면에서 보여준다.
    

### 이번 주 활동 요약(주간 통계)

- 이번 주 생성된 이슈 수
    
- 이번 주 완료된 이슈 수
    
- 이번 주 회의 시간(총합)
    

### 최근 회의 카드(가장 최근 1개)

- 회의 날짜
    
- 회의 이름
    
- 진행 시간
    
- 참여자 목록
    
- 생성된 이슈 개수
    
- 생성 이슈의 GitHub 링크(또는 리스트 링크)
    

### 진행 중 이슈 리스트(우선순위 기반)

- 이슈 번호
    
- 제목
    
- 생성 유저 정보
    
- 생성 일시
    

---

## 7) 텍스트 채팅

### 목적

- 방/회의실에서 커뮤니케이션을 지원한다.
    

### 기능 요구사항

- 입장 시 최신 채팅 **10~20개** 로드
    
- 과거 채팅을 시간순으로 조회(무한 스크롤/페이지네이션 등)
    
- 채팅 메시지 표시 요소:
    
    - 유저 프로필 사진
        
    - 이름
        
    - 시간
        
    - 내용
        
- 채팅 메시지 **수정 / 삭제** 가능(권한 정책 필요: 작성자만 or 관리자도 가능)
    

---

## 8) 회의실 (Real-time Meeting)

### 목적

- OpenVidu 기반 실시간 음성 회의 + 화면 공유 + 채팅 제공
    

### 기능 요구사항

- OpenVidu로 **실시간 음성 대화**
    
- 화면 공유:
    
    - 전체 화면
        
    - 특정 애플리케이션 창
        
    - 브라우저 탭
        
- 텍스트 채팅 제공
    
- 방마다 고유 세션 ID 부여로 보안 강화
    

### 세부 요구사항

|기능|상세|
|---|---|
|세션 관리|고유 세션 ID로 openvidu 자동 연결 / 미인가 사용자 접근 제한|

---

## 9) 이슈 (GitHub 연동)

### 목적

- 이슈를 서비스에서 관리하되, 실제 저장/원장은 GitHub 레포지토리로 반영한다.
    

### 기능 요구사항

- 이슈 목록을 시간순 조회
    
- 이슈 검색
    
- **관리자**는 작성 템플릿 생성/수정/삭제 가능
    
- 사용자가 “이슈 생성” 클릭 시 템플릿 폼 표시
    
- 저장 시 GitHub API 호출 → 실제 레포에 이슈 생성
    
- 생성 결과는 라운지 대시보드에 **실시간 반영**
    

---

## 10) 회의 요약 (Speech-to-Text + AI Summary)

### 목적

- 회의 중 음성을 자동 기록하고, 종료 시 요약/회의록을 생성하여 공유한다.
    

### 기능 요구사항

- 회의록 검색 가능
    
- 회의실 입장 시 **별도 트리거 없이** 음성 인식/기록 프로세스 자동 시작
    
- 종료 버튼 클릭 시:
    
    - 전체 텍스트 스크립트를 서버로 전송
        
    - AI 요약 생성
        
    - 요약본은 **마크다운 또는 에디터 형태로 수정 가능**하게 저장
        
- 생성된 회의록은 해당 방 라운지 대시보드에 **즉시 게시**

# 권한(역할) 기준 요약

|구분|가능한 작업|
|---|---|
|관리자|방 생성, 이슈 템플릿 CRUD, (선택) 채팅 삭제 권한|
