    Feature Request Table

    FR ID Feature Priority Actor/Role User Story Scope / Requirements Acceptance Criteria (AC) Dependencies / Notes
    FR-01 GitHub OAuth 로그인 MUST Guest/User 사용자로서 GitHub 계정으로 로그인하고 싶다. - GitHub OAuth 연동 로그인 - “Login with GitHub”로 로그인 성공- 로그인 성공 시 사용자 식별 가능(프로필 확보) GitHub OAuth App 설정 필요
    FR-02 세션 유지 MUST User 로그인 상태를 유지하고 싶다. - 토큰/세션 기반 로그인 유지 - 새로고침 후에도 로그인 유지- 인증이 필요한 API는 인증 없으면 401 세션이면 Redis/Spring Session 고려
    FR-03 로그아웃 MUST User 로그아웃하여 인증 상태를 초기화하고 싶다. - 세션 종료- 클라이언트 상태 초기화 - 로그아웃 후 보호 페이지 접근 불가- 클라이언트 사용자 정보 초기화
    FR-04 유저 프로필 조회 MUST User 내 프로필을 확인하고 싶다. - GitHub 프로필 기반(이름/아이디/아바타) - 프로필 화면에서 이름/아이디/아바타 노출
    FR-05 방 단위 역할/권한 MUST Admin/Member 방 안에서 역할에 따른 권한이 적용되길 원한다. - 방 단위 관리자/멤버 구분 - 관리자만 가능한 기능 제한 동작- 멤버는 제한 기능 접근 시 거부(403) 권한 테이블/정책 필요
    FR-06 활동 기록(최근 회의/이슈 등) SHOULD User 내 최근 활동을 빠르게 확인하고 싶다. - 최근 참여 회의/생성 이슈 등 기록 - 마이페이지에서 최근 활동 노출(최소 회의) 표시 범위는 MVP에서 축소 가능
    FR-07 마이페이지: 최근 참여 회의 MUST User 로그인 직후 최근 회의를 보고 싶다. - 최근 참여 회의 5~10개- 회의: 제목/참가자 요약/날짜(시간) - 로그인 직후 기본 화면에 리스트 출력- 각 아이템에 제목/참가자/일시 표시 정렬: 최신순
    FR-08 마이페이지: 다가오는 회의(예약) SHOULD User 다가오는 예약 회의를 보고 싶다. - 예정 회의 5~10개- 제목/일시/방 이름(or 썸네일)/참가자 수 - 예약된 회의가 있으면 영역 노출- 없으면 “예정 없음” 상태 표시 캘린더/예약 기능 의존
    FR-09 사이드바: 방 리스트 MUST User 참여 중인 방으로 빠르게 이동하고 싶다. - 로그인 성공 시 참가 방 목록 표시- 썸네일/방 이름 노출 - 사이드바에 내 방이 노출- 방 클릭 시 해당 방으로 이동
    FR-10 방 리스트: 알림 배지 SHOULD User 방에 새 이벤트가 있으면 표시되길 원한다. - 새 이벤트/미확인 메시지/새 회의록/새 이슈 등 표시 - 새 이벤트 발생 시 배지 표시- 확인/읽음 처리 시 배지 해제 Redis 카운터/읽음 포인터 고려
    FR-11 방 생성 MUST(정책) Admin(또는 User) 새 협업 방을 만들고 싶다. - 방 이름 입력하여 생성 - 정책에 따른 생성 권한 적용(관리자만/전체) “관리자만”이면 Admin만 버튼 노출
    FR-12 방 입장 및 레포 연결 MUST User 방에 들어가 프로젝트 레포를 연결하고 싶다. - 방 입장 시 레포 생성/불러오기 가능 - 레포 생성/연결 성공 시 방에 반영 GitHub Repo API 연동
    FR-13 멤버 초대(GitHub collaborator) MUST Admin GitHub ID로 멤버를 초대하고 싶다. - GitHub ID 검색- Collaborator 자동 초대 - 검색 결과 노출- 초대 성공/실패 피드백 표시 GitHub 권한/토큰 scope
    FR-14 방 내부: 회의 리스트(진행/완료) MUST User 방에서 회의 상태별 리스트를 보고 싶다. - 진행 중/완료된 회의 표시 - 상태별 리스트/탭/섹션으로 구분 표시 회의 상태 모델 필요
    FR-15 회의 예약 CRUD MUST Admin 회의를 예약/수정/취소하고 싶다. - 예약 추가/수정/취소(관리자)- 상태: 예정/진행/완료/취소 - 관리자만 CRUD 가능- 취소 시 상태가 “취소”로 표시 캘린더 위젯과 연동
    FR-16 캘린더: 회의 표시 MUST User 캘린더에서 회의가 있는 날짜를 한눈에 보고 싶다. - 날짜에 예약/완료 회의 표시 - 회의가 있는 날짜에 표시(점/뱃지 등)- 날짜 클릭 시 회의 목록 확인
    FR-17 초대 링크 생성/삭제 MUST Admin 초대 링크를 만들어 공유하고 싶다. - 링크 생성/삭제 - 링크 생성 시 URL 발급- 삭제 시 해당 링크 무효화 토큰/UUID/서명 기반
    FR-18 초대 링크 유효기간 설정/수정 MUST Admin 초대 링크 만료를 설정하고 싶다. - 유효기간 설정/수정 - 만료 후 접근 시 “만료됨” 안내 Redis TTL 또는 DB expiry
    FR-19 초대 링크 랜딩 페이지 MUST Guest/User 초대 링크로 방 정보를 보고 참여하고 싶다. - 방 제목/참가자 수/레포 정보 표시- 참여(입장) 가능 - 랜딩에서 정보 노출- 참여 클릭 시 방 가입 처리 로그인 필요 여부 정책 정의
    FR-20 라운지: 주간 활동 요약 MUST User 방 활동 요약을 한 화면에서 보고 싶다. - 주간 생성/완료 이슈 수- 주간 회의 시간 총합 - 주간 통계 카드 노출- 데이터 없으면 0 처리 집계 로직 필요
    FR-21 라운지: 최근 회의 카드 MUST User 가장 최근 회의를 빠르게 확인하고 싶다. - 최근 1개 회의 카드- 날짜/이름/진행시간/참여자/생성 이슈 수/이동 - 최근 회의가 있으면 카드 표시- 클릭 시 회의 상세/회의록 이동
    FR-22 라운지: 진행 중 이슈 리스트 MUST User 진행 중인 이슈를 확인하고 싶다. - 우선순위 기반 리스트- 번호/제목/생성 유저/생성 일시 - 리스트가 우선순위대로 표시- 항목 클릭 시 상세 이동
    FR-23 라운지: 다가오는 회의 위젯 SHOULD User/Admin 다음 회의를 한눈에 보고 바로 입장하고 싶다. - 다음 예약 1개(or n개)- 관리자는 예약 CRUD 진입 - “입장” 버튼 제공- 관리자는 관리 버튼 노출 FR-15/16 의존
    FR-24 텍스트 채팅: 최신 로드 MUST User 입장 시 최근 채팅을 바로 보고 싶다. - 최신 10~20개 로드 - 방/회의 입장 시 최신 N개 표시 페이지네이션 필요
    FR-25 텍스트 채팅: 과거 조회 MUST User 이전 채팅을 무한 스크롤로 보고 싶다. - 시간순 조회- 무한 스크롤/페이지네이션 - 스크롤 시 과거 메시지 추가 로드 인덱스 설계 중요
    FR-26 텍스트 채팅: 수정/삭제 SHOULD User/Admin 내 메시지를 수정/삭제하고 싶다. - 본인 메시지 수정/삭제- (선택) 관리자 삭제 - 권한 정책대로 동작 감사 로그 선택
    FR-27 회의실: OpenVidu 음성 회의 MUST User 음성으로 실시간 회의를 하고 싶다. - OpenVidu 기반 음성 회의 - 다자 음성 연결 성공 OpenVidu 인프라 필요
    FR-28 회의실: 화면 공유 MUST User 화면 공유를 하고 싶다. - 전체/앱/탭 공유 - 공유 시작/중지 가능 브라우저 권한 처리
    FR-29 회의실: 회의 채팅 MUST User 회의 중에도 채팅하고 싶다. - 텍스트 채팅 제공 - 회의 채팅 송수신 가능 FR-24~26 재사용 가능
    FR-30 회의실: 세션 ID로 보안 강화 MUST System 방마다 고유 세션 ID로 보안을 강화하고 싶다. - 방별 고유 세션 ID 부여 - 다른 방 세션으로 접근 불가 토큰/세션 매핑
    FR-31 이슈 목록/검색 MUST User 이슈를 조회/검색하고 싶다. - 시간순 조회- 검색 - 목록/검색 결과 표시 GitHub 이슈 동기/캐시 전략
    FR-32 이슈 템플릿 CRUD MUST Admin 이슈 템플릿을 관리하고 싶다. - 템플릿 생성/수정/삭제 - 관리자만 CRUD 가능 템플릿 저장소(DB)
    FR-33 템플릿 기반 이슈 생성(GitHub 반영) MUST User 폼으로 이슈를 만들고 GitHub에 반영하고 싶다. - 폼 입력 → GitHub API 이슈 생성 - GitHub에 이슈 생성 성공- 실패 시 이유 노출 OAuth scope/레포 권한
    FR-34 이슈 생성 결과 라운지 실시간 반영 MUST User 이슈 생성 결과가 라운지에 바로 보였으면 좋겠다. - 생성 후 라운지에 실시간 반영 - 생성 직후 리스트/카운트 갱신 WS/SSE + Redis 이벤트 고려
    FR-35 회의 요약: 음성 기록 자동 시작 MUST User 회의실 입장 시 자동으로 기록되길 원한다. - 입장 시 STT 자동 시작 - 입장 후 기록 상태 표시(ON) 녹음/전송 파이프라인 필요
    FR-36 회의 종료 시 요약 생성 플로우 MUST User 종료 시 스크립트→요약 생성→저장하고 싶다. - 종료 버튼 클릭- 스크립트 전송 → AI 요약 생성- 마크다운/에디터로 수정 저장 - 종료 후 요약 생성 결과 확인 가능- 수정 후 저장 시 영구 반영 AI 워커/큐(Redis Streams/Kafka)
    FR-37 회의록 검색 MUST User 회의록을 검색하고 싶다. - 회의록 검색 가능 - 키워드로 검색 결과 반환 DB FTS / Elastic 선택
    FR-38 회의록 라운지 즉시 게시 MUST User 생성된 회의록이 라운지에 즉시 보여야 한다. - 생성 후 라운지 즉시 게시 - 요약 완료 후 라운지 카드/리스트에 노출 실시간 이벤트/캐시
